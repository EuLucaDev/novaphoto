Nova Photo portable mode

While this file sits next to novaphoto.exe, Nova Photo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Nova PhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move Nova Photo with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Novaphoto) instead.
If Nova PhotoData can't be written (for example on a read-only drive), Nova Photo says so and
uses %APPDATA%\Novaphoto instead.
